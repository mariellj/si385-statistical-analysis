# SI 385 — Statistical Analysis Projects

A portfolio of applied statistical analysis coursework using Python, pandas, matplotlib, and marimo. Each project examines how analytical choices affect conclusions.

## Projects

### [NYC Restaurant Health Inspection Analysis](nyc-restaurant-inspections/)
Reassessing an inherited comparison of chain and independent restaurants by changing the unit of analysis, testing chain definitions, and conditioning on cuisine.

## Notes
This repository contains student coursework. The inherited starter notebook is attributed to the course materials; the modified notebook contains the student's analysis. Datasets are not redistributed here.
